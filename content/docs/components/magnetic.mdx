## Usage

After you add the component with the CLI, import it from your UI folder:

```tsx
import { Magnetic } from "@/components/prsui/magnetic";

export function MyComponent() {
  return (
    <Magnetic>
      <button>Drag me with your cursor</button>
    </Magnetic>
  );
}
```

Wrap any element — buttons, cards, avatars — with `Magnetic` and it will follow
the cursor while hovered, then spring back to rest on leave. The effect is
disabled on touch devices and when the user prefers reduced motion.

## Props

| Prop         | Type        | Default | Description                                          |
| ------------ | ----------- | ------- | ---------------------------------------------------- |
| `children`   | `ReactNode` | -       | The element that gets pulled toward the cursor       |
| `className`  | `string`    | -       | Additional CSS classes merged onto the wrapper       |
| `strength`   | `number`    | `0.35`  | Fraction of the pointer distance to travel (0-1)     |
| `maxOffset`  | `number`    | `32`    | Maximum travel distance in px from the rest position |
| `hoverScale` | `number`    | `1.04`  | Scale applied while the pointer is inside            |
